# 将页面做成 Stitch 画面

把用户指定的稳定页面做成 Google Stitch 项目里的桌面画面。每一页只保留一张画面。本地 HTML 是这张画面的合同。Stitch 中的 HTML 与这份合同字节相同，才算这一页完成。

先读 [Stitch 工具限制](references/stitch-tool-limits.md)。那些限制来自一次已完成的画面制作，调用前仍以当前工具的参数为准。

## 范围

- 只做用户点名的页面，或产品导航和主流程里的稳定页面。
- 顶栏外壳、账号菜单、登录页、空态、加载态和错误态默认不做。用户点名后才做。
- 图标和 Logo 只在用户要求一致时才纳入合同。未要求时，记录差异并继续。
- 颜色、字号、圆角和字体以页面来源为准。来源有设计 token 文件时，以该文件为准，不手改该文件。
- 这个 skill 不授权修改来源产品的代码。

## 做一页

1. 确认 Google Stitch 可用。只读调用失败时停止，不创建项目。
2. 打开来源页面，并读取决定该页结构的源码。记录区域顺序、可见文案、宽高、圆角和色值。缩略图和截图像素不能作为合同。
3. 把记录写成一份本地 HTML。色值和尺寸写死。不要使用会随主题改色的类名。
4. 项目只建一次。用户已指定项目时，沿用该项目。
5. 来源有设计 token 文件，且项目里还没有对应设计系统时，上传一次并创建设计系统。设计 token 未变时不要重传。
6. 这一页还没有画面时，生成一张桌面画面，只为取得 screen ID。之后不要为同一页再生成。
7. 用本地 HTML 替换这一个 screen ID 的 HTML。
8. 替换后读取新的 HTML 文件 ID。文件 ID 未变时，替换没有生效。不要把工具的成功返回当作完成。
9. 取回完整 HTML，与本地合同做 sha256。两边相同才接受。工具输出被截断，或长度小于本地文件时，不接受。
10. 把这张画面放上画布，且不要盖住已有画面。调用前重新读取项目。提交时保留全部已有实例。只新增或更新这一页的实例。隐藏重复的失败画面。

一页的差异只改本地 HTML，再替换同一个 screen ID。不要并行调用 Stitch 写操作。连接失败时，先读取画面和文件 ID，确认没有生效后再重试。

## 完成证据

每一页报告：

- 来源页面
- screen ID
- HTML 文件 ID
- sha256 是否与本地合同相同
- 用户允许的差异

全部指定页面都有一张未隐藏的画面，且哈希相同，任务才完成。未知页面、未取回的全文和未核对的哈希都保持未知，不标成完成。

## 停止

- Stitch 不可用。
- 来源页面打不开，且源码不足以写出合同。
- 同一页的替换两次都没有改变 HTML 文件 ID。
- 写画布会丢掉已有实例，且当前项目状态无法重新读取。
