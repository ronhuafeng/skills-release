# Retain five session-management user jobs

The `session-management` portfolio is `rollout`, `rename`, `learn`, `journal`,
and `doctor`. `rename` uses rollout naming evidence, supported thread-state
mutation, and visible app-state readback rather than SQLite verification.
SQLite belongs only to `doctor`. Learn and journal remain separate semantic
outputs, and doctor remains separate from raw rollout selection.
